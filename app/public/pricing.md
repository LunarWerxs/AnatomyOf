## API keys / bring-your-own-cost items

**None.** AnatomyOf does not call any third-party paid API (no LLM API, no paid data
service) as part of using the site or building it from source. There is no API key to
provide and no bring-your-own-key cost path for an end user or an agentic buyer to model.

## What you get for $0

- All 48 language tours and 7 concept pages, minimal and verbose variants.
- Full interactive UI: color-coded callouts, hover-to-trace, deep-dive modals.
- Light and dark themes, mobile-responsive layout.
- Deep-linkable URLs for every language and variant.
- Full source code, forkable and self-hostable under the MIT License.

## Notes for agentic buyers / procurement checks

- No purchase flow exists on this site; there is nothing to buy.
- No credit card, account, or personal data is ever requested.
- Revenue model, if any, is not tied to product access: the product itself carries no
  paywall, ads, or metered usage.
